Some of these changes and most of the bug fixes were in 26.3.0 but weren't listed.

- Added a "Custom" preset indicator, shown when the current settings don't match any preset
- Default config values now match the "Disable All" preset
- Added Mossy Deepslate block set: mossy cobbled deepslate and mossy deepslate bricks with stairs, slabs and walls, and infested mossy deepslate bricks
- Added deepslate dungeon variant: dungeons in the deepslate layer generate with cobbled deepslate and mossy cobbled deepslate (requires the Mossy Deepslate block set)
- Added deepslate mineshaft variant: mineshafts in the deepslate layer use spruce wood and lanterns, have more frequent and continuous rails, activator rails powered by redstone torches, TNT minecarts and more chest minecarts, with configurable chances
- Deepslate mineshaft lanterns are placed on walls if Lanterns Belong on Walls is installed
- Merged durability, tool stat and weapon stat options into a single item stats option that targets lists of item IDs and item tags
- Ore size multiplier is now depth-based with configurable minimum and maximum multipliers and heights, and only applies to the Overworld
- Added option to stop villagers from losing their profession when their workstation is removed
- Added options for potent sulfur geyser eruption frequency, and for the frequency and range of potent sulfur geyser and trial spawner sounds
- Added option to adjust ravager roar knockback
- Made eating cancellation on damage, shield projectile damage reduction and Mastercutter advancement removal configurable
- Frost Walker early trigger now freezes water ahead of moving players instead of shrinking the freezing radius
- Random chests in woodland mansions and ocean monuments are now only placed in locations enclosed by the structure, and default chances were adjusted
- Fixed saturation draining at full health when rapid healing is not disabled
- Fixed the Ender Dragon never dropping XP and fishing never dropping XP when their options are disabled
- Fixed smelting and cooking recipe XP being removed when recipe XP swaps are not configured
- Fixed curse and Frost Walker enchanted books being added to loot tables when their options are disabled
- Fixed large ancient debris veins always using the small vein size
- Fixed tool stats being modified when the "Disable All" preset is selected
- Fixed Frost Walker early trigger being applied twice
- Fixed the anti-farm pack not removing fuels
- Fixed a crash with the early game extension tutorial
- Fixed crashes when turning shader presets off or loading more than 10 shader presets
- Fixed the preset reverting to "Custom" after restarting the game
- Updated mod documentation
